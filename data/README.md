# Data

Datasets and benchmarks used for training and evaluation. Raw datasets are not
committed (see `.gitignore`); this folder holds pointers and, later, the loading
and preprocessing scripts.

## Planned datasets
- CICIDS2017, CIC-DDoS2019 — network intrusion / DDoS
- BoT-IoT, TON_IoT — IoT attack traffic
- UNSW-NB15 — intrusion detection
- SCIONLab traces (to be collected) — path-aware features

Loading scripts will live under `tools/` as the experimental phase begins.
